# Predicting Genre and Chart Success from Song Lyrics Using NLP

NLP project that classifies song genres and predicts Billboard chart success based on lyrics alone, using songs from the Billboard Year-End Hot 100 (2003–2023) matched with lyrics from Genius.com.

---

## Project structure

```
NLP_final_project/
├── src/
│   ├── main.py                 ← single entry point — run this
│   ├── genre_pipeline.py       ← genre classification pipeline (sklearn + DistilBERT)
│   ├── hit_prediction.py       ← hit prediction pipeline
│   ├── cleaning.py             ← Kaggle download + Billboard merge
│   ├── preprocessing.py        ← NLP preprocessing pipeline
│   ├── feature_engineering.py  ← numerical lyric features
│   └── scraper.py              ← Billboard Year-End chart scraper
├── data/                       ← gitignored; generated by the pipeline

├── outputs/                    ← gitignored; generated by the pipeline
├── report/
├── .gitignore
├── requirements.txt
└── README.md
```

## Setup

**Requirements:** Python 3.10+

```bash
pip install -r requirements.txt
```

A Kaggle API key is required to download the Genius lyrics dataset automatically.
See: https://www.kaggle.com/docs/api

For DistilBERT fine-tuning, a GPU is strongly recommended. CPU training works but takes approximately 60 minutes per epoch on this dataset size.

---

## Running the pipeline

Everything runs from a single command (from the project root):

```bash
python src/main.py
```

This runs both pipelines sequentially: genre classification first, then hit prediction.

To run a single pipeline:

```bash
python src/genre_pipeline.py
python src/hit_prediction.py
```

---

## First-time setup

The data acquisition steps are disabled by default to avoid re-running long operations. On first run, open the relevant file and set the flags:

**Scrape Billboard data** — open `src/scraper.py` and set:
```python
RUN_SCRAPER = True
```
Then run `python src/scraper.py`. Set back to `False` after.

**Download and clean Genius lyrics** — open `src/cleaning.py` and set:
```python
RUN_GENRE_CLEANING = True   # for genre classification dataset
RUN_HIT_CLEANING   = True   # for hit prediction dataset
```
Then run `python src/cleaning.py`. The first download is approximately 2 GB and takes several minutes. Set flags back to `False` after.

**Enable DistilBERT fine-tuning** — open `src/genre_pipeline.py` and set:
```python
RUN_HF_MODEL = True
```
GPU recommended. Training runs for 3 epochs on a sample of 5,000 songs.

Once all data files exist in `data/`, all flags stay `False` and subsequent runs go straight to training.

| File                              | Description                                    |

| `genre_confusion_matrix_*.png`    | Confusion matrix per genre model               |

| `hit_confusion_matrix_*.png`      | Confusion matrix per hit prediction model      |
| `hit_model_comparison.png`        | F1 scores across hit prediction models         |
| `hit_results.json`                | Numeric results for all hit models             |
