# Genre Classification of Billboard-Charted Song Lyrics

NLP project that classifies song genres based on lyrics, using songs that
appeared on the Billboard Year-End Hot 100 charts (2003–2023).

## Setup

**Requirements:** Python 3.10+

```bash
pip install -r requirements.txt
```

A Kaggle API key is required for the lyrics download step.
See: https://www.kaggle.com/docs/api

---

## Running the pipeline

Everything runs from a single command (from the project root):

```bash
python src/main.py
```

### First-time setup

The two data acquisition steps are disabled by default to avoid re-running
long operations. On first run, open `src/main.py` and set:

```python
FORCE_SCRAPE        = True   # scrapes Billboard (run once, then set back to False)
FORCE_PREPROCESSING = True   # downloads Genius dataset (~2 GB, takes several minutes)
```

After the data files exist in `data/`, set both flags back to `False` —
subsequent runs will skip straight to training.

### Outputs

## Project structure

```
nlp_genre_classifier/
├── src/
│   ├── main.py               ← single entry point — run this
│   ├── scraper.py            ← Billboard Year-End chart scraper
│   ├── checker.py            ← Billboard dataset validator
│   ├── cleaning.py           ← Genius lyrics download + merge
│   ├── preprocessing.py      ← NLP preprocessing pipeline
│   ├── models.py             ← model definitions + train/test split
│   └── evaluation.py         ← metrics, confusion matrices, bar chart
├── data/                     ← gitignored; generated by the pipeline
├── outputs/                  ← gitignored; generated by main.py
├── report/
│   └── report.pdf
├── .gitignore
├── requirements.txt
└── README.md
```

Each module in `src/` can also be run standalone for development purposes.
